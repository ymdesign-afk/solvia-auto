📋 GitHub / Vercel へのアップロード手順

1

下記の「テキストファイル」をすべてダウンロードしてください。

2

「画像ファイル」は右クリック →「名前を付けて保存」でダウンロードしてください。

3

GitHubで solvia-auto リポジトリを作成し、フォルダ構成を守ってアップロード：
css/style.css、css/pages.css、js/main.js、images/（画像）

4

Vercelで GitHub リポジトリを連携してデプロイ完了！
