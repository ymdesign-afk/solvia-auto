選ばれる6つの理由

No.アイコンタイトル説明文
①fas fa-clipboard-check状態を正直に、すべて開示傷・走行距離・修復歴など、気になる情報をすべて開示します。「後から知った」がないように。
②fas fa-award全国オークションから1台を厳選在庫を持たず、ご要望に合わせて全国のオークションから最適な車両を仕入れます。
③fas fa-shield-alt押し売りなし。あなたのペースで「今すぐ決めてください」は言いません。納得いくまでご検討ください。
④fas fa-truck-fast陸送・全国対応全国どこへでも陸送でお届けします。東京に来られなくても大丈夫です。
⑤fas fa-credit-cardローン対応・頭金なし相談可提携ローン会社をご利用いただけます。頭金なしでのご相談も承っています。
⑥fab fa-lineLINEでのやりとりOKLINEでの商談・質問対応も可能です。お気軽にメッセージをどうぞ。

FAQ（よくあるご質問）

質問回答
新車も対応できますか？ はい、対応可能です。メーカー・車種のご希望をお聞かせいただければ、新車のお見積もりもご提案します。まずはお気軽にご相談ください。
遠方でも購入できますか？ はい、全国対応しています。陸送でのお届けが可能ですので、実際に来店いただかなくてもお取引できます。お車の状態はしっかりご説明しますのでご安心ください。
査定だけでもお願いできますか？ もちろんです。査定のみのご相談も大歓迎です。売却をご検討中の方はもちろん、「まず価格を知りたい」という方もお気軽にどうぞ。
車検はついていますか？ 車両によって異なります。車検の有無や残存期間はご説明の際にお伝えします。車検整備をご希望の場合は別途ご相談ください。
ローンは使えますか？ ご利用いただけます。提携ローン会社をご紹介します。頭金なしでのご相談も承っておりますので、まずはお気軽にお問い合わせください。審査基準はローン会社により異なります。
まずは話を聞いてもらうだけでも大丈夫ですか？ もちろんです。「まだ決めていない」「なんとなく気になっている」という段階でも、ぜひご相談ください。無理な提案や勧誘は一切しません。

スクロール連動ヘッダー

項目仕様
発火条件スクロール量 > 50px
トリガーJavaScript window.addEventListener('scroll', ...)
クラス操作ヘッダーに .scrolled クラスを付与 / 削除
CSS 変化背景: 透明 → 白、ロゴ: 白 → 黒、テキスト: 白 → ネイビー
アニメーションtransition: all 0.3s ease

ハンバーガーメニュー（SP用）

項目仕様
表示条件≤ 768px
開閉トリガーハンバーガーボタンクリック
クラス付与header・nav に .nav-is-open クラスを付与
オーバーレイフルスクリーン、背景色: #1a3a5c
ボタン変化3本線 → ✕（CSS アニメーション）
メニュー項目タップ自動的にメニューを閉じる

FAQ アコーディオン

項目仕様
動作質問クリックで回答の表示 / 非表示を切替

アイコン「＋」→「－」
アニメーションtransition: max-height 0.3s ease

スクロールアニメーション（AOS）

項目仕様
ライブラリAOS（Animate On Scroll）v2.3.4
CSS CDNhttps://cdn.jsdelivr.net/npm/aos@2.3.4/dist/aos.css
JS CDNhttps://cdn.jsdelivr.net/npm/aos@2.3.4/dist/aos.js
